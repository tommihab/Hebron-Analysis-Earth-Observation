# ArcGIS Pro — Hebron Land-Cover Change

## Project Package

**File:** `Hebron_LandCover_Change_2026.ppkx`

**Size:** Approximately 300 MB

**Download:** [[Google Drive](https://drive.google.com/file/d/1hxyR0QHLAPOKQoZXBgkHiraGJd2gZTok/view?usp=sharing)]

## Contents

The ArcGIS Pro project contains the combined spatial analysis and visualisation of:

- Potential vegetation loss
- Potential built-up expansion
- Potential built-up reduction
- Spatial overlap between vegetation loss and built-up expansion

**Study period:** 2020–2022 baseline compared with 2026

**Coordinate reference system:** EPSG:32636 (analysis exports)

## How to Open

1. Download the `.ppkx` file.
2. Open ArcGIS Pro.
3. Open the project package using ArcGIS Pro.
4. Check that all layers and map layouts display correctly.
