# QGIS — Hebron Olive Land-Cover Change Classification

## QGIS Project

**File:** `olive_loss_west_bank.qgz`

## Contents

The QGIS project contains the spatial visualisation of the olive land-cover change classification analysis in the Hebron study area.

The project uses the following layers:

- **Hebron AOI:** Study area boundary (`hebron_aoi.geojson`)
- **Reference-period RGB composite:** `Hebron_RGB_Reference_2020_2022.tif`
- **Post-period RGB composite:** `Hebron_RGB_Post_2025_2026.tif`
- **MSAVI2 Change Classification:** `Hebron_MSAVI2_Change_Classification.tif`


**Study period:** 2020–2022 reference period compared with 2025–2026 post-period.

**Coordinate reference system:** EPSG:32636 (UTM Zone 36N).

## Data and Download

All datasets required to reproduce the QGIS visualisation are available in Google Drive:

**Download:** [Google Drive – Hebron Project Data](https://drive.google.com/drive/folders/1eF8lyTNn185a_0Wya1c3Gr-3KQGhlFh9?usp=drive_link)

Download the four layers listed above before opening the QGIS project.

## How to Open

1. Download the QGIS project (`.qgz`) from this repository.
2. Download the required layers from Google Drive.
3. Open the project in QGIS.
4. If necessary, update the paths to the downloaded layers.
5. Check that all layers are loaded and displayed correctly.
