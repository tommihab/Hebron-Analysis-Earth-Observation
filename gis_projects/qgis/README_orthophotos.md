# QGIS — Orthophotos Analysis Wadi Sair

## QGIS Project

**Files:** `orthophotos_analysis_wadi_sair.qgz`


## Contents

The QGIS project contains the spatial visualisation of the orthophotos land cover classification and change analysis in Wadi Sa'ir study area.

The project uses the following layers:

- **Wadi Sa'ir AOI:** Study area boundary (`classification_ROI.geojson`)
- **Land Cover Classified Raster for 2021:** `Wadi_Sair_2021_classification.tif`
- **Land Cover Classified Raster for 2023:** `Wadi_Sair_2023_classification.tif`
- **Differences in Tree Classification 2021-2023:** `Wadi_Sair_Tree_Changes_2021_2023.gpkg`


**Study period:** 2021–2023.

**Coordinate reference system:** EPSG:32636 (UTM Zone 36N).

## Data and Download

All datasets required to reproduce the QGIS visualisation are available in Google Drive:

**Download:** [Google Drive – Olive Land Cover Classification Data]([https://drive.google.com/drive/folders/1eF8lyTNn185a_0Wya1c3Gr-3KQGhlFh9?usp=drive_link](https://drive.google.com/drive/folders/1LN9wz3L8HzCa_OVkisOxPq2YCg6O2yaJ?usp=drive_link))

Download the four layers listed above before opening the QGIS project.

## How to Open

1. Download the QGIS project (`.qgz`) from this repository.
2. Download the required layers from Google Drive.
3. Open the project in QGIS.
4. If necessary, update the paths to the downloaded layers.
5. Check that all layers are loaded and displayed correctly.
