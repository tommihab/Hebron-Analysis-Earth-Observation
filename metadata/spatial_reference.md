# Spatial reference and geometry

Document the CRS of every input, processing stage, and output. Record reprojection parameters, pixel grid alignment, resolutions, and any detected misregistration.

- High-resolution GeoMOLG orthophoto study: EPSG:28191 (verify for each downloaded tile).
- Regional Sentinel-2 analysis: record actual CRS of exports (do not assume all outputs use the same CRS).
- Local area of interest: record boundary file, extent, and source.
