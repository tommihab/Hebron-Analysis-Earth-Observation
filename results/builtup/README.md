# Built-up analysis outputs

Place small, shareable probability/change maps, figures, and tables here.

For each output, document:
- Filename and description
- Code version / Git commit and processing date
- Source periods and study-area version
- CRS, resolution, thresholds, and output units
- Whether a mapped area represents an inferred probability change or independently verified construction
- Validation data and limitations

Large raster exports should normally be linked from external storage. No result values are asserted in this starter template.
