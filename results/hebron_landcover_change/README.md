# Hebron Land-Cover Change Analysis — Results

## Overview

This folder contains the combined results of vegetation and built-up land-cover change detection in the Hebron study area, West Bank.

Two Google Earth Engine workflows were used:

- **Vegetation change:** Sentinel-2 Level-2A imagery, MSAVI2 and ESA WorldCover 2020.
- **Built-up change:** Google Dynamic World V1 built-class probabilities.

Both analyses compare a June–September 2020–2022 baseline with the corresponding period in 2026.

## Map Outputs

The combined map visualises potential vegetation decline and changes in built-up land cover.

The results were integrated and visualised using ArcGIS Pro and ArcGIS Online.

## Limitations

The mapped changes represent potential land-cover changes identified through satellite-based methods.

Results have not yet been independently validated and should not be interpreted as confirmed vegetation removal, building construction, or demolition.

Differences in observation conditions, seasonal vegetation variability, classification uncertainty, and mixed pixels may affect the detected patterns.
