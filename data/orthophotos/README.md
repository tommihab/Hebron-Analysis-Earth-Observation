# Data inventory — Khirbet al-Fakheit

This directory documents the data without committing very large imagery or model files.

| Planned/generated output | Intended role | GitHub policy |
|---|---|---|
| `Masafer_Yatta_AOI.geojson` | The 1 km² AOI polygon (exported by the notebook) | Small file can be committed after generation |
| `Orthophoto_2021.tif`, `Orthophoto_2022.tif`, `Orthophoto_2023.tif` | Original-resolution RGB mosaics, 6668 × 6668 px, EPSG:28191 | External storage; verify GeoMOLG redistribution license |
| `orthophotos_30cm/Orthophoto_{year}_30cm.tif` | Resampled 3334 × 3334 px mosaics | External storage |
| `test_patches/Patch_{year}.png` | Test patches and comparisons | Publish only if license permits |
| `building_segmentation/Building_Probability_{year}.tif` | Full-AOI building probability maps | External storage / links |
| `building_segmentation/Building_Mask_{year}.tif` | Binary building masks | External storage / links |
| `building_change_detection/Building_Change_{period}.tif` | Pairwise four-class change raster | External storage / links |
| `building_change_detection/Building_Change_Statistics.csv` | Calculated change statistics, generated by the notebook | Small; add to GitHub after a successful verified run |

**Original imagery should not be put in this repository by default.** Source URLs are listed in `metadata/khirbet_orthophoto_data_sources.csv`. Confirm licensing and any attribution requirements prior to publishing derivative image files.

The Colab notebook currently stores downloads under `/content/orthophotos`, so they may be lost when the Colab session ends. Move archival outputs to durable cloud storage with clear filenames and a retrieval date.
