# Data

The datasets used and generated in this project are stored in Google Drive due to their large file size.

**Access the data:** [Google Drive – Project Datasets](https://drive.google.com/drive/folders/1eF8lyTNn185a_0Wya1c3Gr-3KQGhlFh9?usp=drive_link)

### Required input

- **ROI (`.geojson`):** Required to run the notebook. It defines the Region of Interest (ROI) used for the analysis.

### Generated and supplementary files

The notebook generates additional files during execution. These outputs, together with other supplementary files, are also provided in the Google Drive folder.

Please download the ROI GeoJSON before running the notebook. The other files are available for reference and to access the results without having to rerun the entire analysis.
