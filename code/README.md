# Code

- `gee/`: Google Earth Engine JavaScript scripts and/or links to hosted code.
- `preprocessing/`: downloads, mosaicking, reprojection, alignment, quality checks.
- `landcover_analysis/`: indices, compositing, land-cover maps and change detection.
- `building_detection/`: pretrained building segmentation and post-processing.
- `notebooks/`: exploratory and end-to-end notebooks.

Each script or notebook should include inputs, configuration, output location and run instructions. Never commit API tokens or passwords.
